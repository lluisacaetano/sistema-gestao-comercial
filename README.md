# Sistema de Gestão Comercial

Sistema de gestão comercial estilo iFood desenvolvido com React.

## Funcionalidades

- Interface de e-commerce moderna
- Catálogo de produtos
- Carrinho de compras
- Sistema de pedidos

## Tecnologias

- React
- JavaScript
- CSS/SCSS
- HTML

## Como Executar

```bash
cd client
npm install
npm start
```
